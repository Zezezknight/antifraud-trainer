# 🛡️ Антискам-тренажер для «Авито»

> **Антискам-тренажер** — это интерактивное обучающее веб-приложение, созданное для отработки навыков безопасных сделок.

Пользователь регистрируется на платформе, выбирает сценарий и погружается в мессенджер-подобный интерфейс. Принимая решения в диалогах, он получает мгновенный фидбек, развернутый отчет об ошибках и рекомендации. 
Система геймификации (начисление очков, уровни, таблица лидеров) мотивирует пользователей соревноваться и повышать свою цифровую грамотность.

## 🚀 Быстрый старт

**Требования к окружению:**
* **Go**: `v1.26.2+`
* **PostgreSQL**: `v18.0+`

Клонируйте репозиторий и запустите проект через Docker:

```bash
git clone git@github.com:Zezezknight/avito-antifraud-trainer.git
cd ./avito-antifraud-trainer

# Настройка переменных окружения
mv .env.example .env

# Запуск контейнеров
docker compose up -d
```

## 📂 Структура репозитория

```text
.
├── backend/                  # Серверная часть приложения (Go)
│   ├── cmd/server/           # Точка входа в приложение (main)
│   ├── init-scripts/         # Скрипты инициализации БД
│   ├── internal/             # Изолированная бизнес-логика
│   │   ├── auth/             # Авторизация и работа с JWT
│   │   ├── config/           # Управление конфигурациями
│   │   ├── domain/           # Доменные модели и сущности
│   │   ├── dto/              # Объекты передачи данных
│   │   ├── handler/          # HTTP-хендлеры, роутер и Swagger-документация
│   │   ├── middleware/       # Промежуточное ПО (аутентификация, логирование)
│   │   ├── repository/       # Слой данных (PostgreSQL + миграции)
│   │   ├── service/          # Слой сервисов (основная бизнес-логика)
│   │   └── userctx/          # Работа с контекстом пользователя
│   ├── .env.example          # Шаблон переменных окружения
│   ├── .golangci.yaml        # Конфигурация линтера
│   ├── Dockerfile            # Инструкции сборки образа
│   └── go.mod / go.sum       # Управление зависимостями
├── docs/                     # Проектная документация и контент сценариев
├── frontend/                 # Исходный код клиентской части
├── docker-compose.yml        # Оркестрация контейнеров (Backend, Frontend, Postgres)
└── README.md                 # Документация репозитория

```
