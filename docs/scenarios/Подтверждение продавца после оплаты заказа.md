# 📄 Сценарий №2: Подтверждение продавца после оплаты заказа

## 1. Метаданные сценария (Карточка в БД `scenarios`)

* **ID сценария (`id`):** `2`
* **Название (`title`):** Подтверждение продавца после оплаты заказа
* **Описание (`description`):** Покупатель уже оформил заказ. В переписке продавцу пишет сотрудник поддержки Avito — чтобы система оформила выдачу товара и перевела оплату, нужно подтвердить личность продавца.
* **Роль (`role`):** `seller` *(Продавец)*
* **Сложность (`difficulty`):** `hard` *(Сложный)*
* **Необходимо сценариев этого уровня (`required_scenarios_this_level`):** `0` *(Доступен сразу — это первый `hard`-сценарий для роли `seller`)*
* **Стартовый узел (`start_node_id`):** `8`

## 4. Механика начисления очков (Scoring System)

* 🏆 **100/100 очков (`green`):** Идеальное прохождение (`Узел 8` ➔ `Узел 9` ➔ `Узел 10` ➔ **Узел 14**). Пользователь отразил все три попытки — код, ссылку и звонок.
* ❌ **0/100 очков (`red`):** Код передан сразу (`Узел 8` ➔ **Узел 12**).
* ❌ **0/100 очков (`red`):** Кража аккаунта по ссылке (`Узел 8` ➔ `Узел 9` ➔ **Узел 13**).
* ❌ **0/100 очков (`red`):** Провал по телефону (`Узел 8` ➔ `Узел 9` ➔ `Узел 10` ➔ **Узел 11**).

> В этом сценарии нет промежуточных «жёлтых» исходов: любой переданный код из смс — на любом этапе и даже один раз — уже считается провалом сценария, а не частичным успехом. Полные 100 очков даются только за отказ от всех трёх попыток мошенника подряд.
